# 人生の社交教練

**問題**：看到網路上很多人常因為不知道該如何回應某個人（曖昧對象、上司）的訊息，而截圖出來向廣大網友求助。也看過女生將與另一半的對話截圖po出，抱怨男友實在是很不懂女人心，引發熱烈討論。此現象造成很多人越來越害怕回覆訊息，深怕回的不對，讓對象跑了或是讓朋友、上司生氣。

**目的**：這個專案的目的是為了協助有此困擾的你回覆他人訊息，你可以隨時向本系統增減對方喜好、雷區、個性、生活習慣等等，系統會彙整並參考這些條件，提供你最適合的訊息參考回覆。讓你在猜不透對方真實想法或不知道該怎麼回覆時，給你最完美的建議，無負擔建立良好社交。

**主要功能與作法**：
1. 條件新增：當使用者在系統輸入該人物的相關條件時（如：喜好、個性），系統會使用LLM將新資料與原有資料做比對與彙整，若為新的人物條件，該條件將會新增為RAG或提示詞（擇一）
2. 訊息回覆建議：當使用者詢問要如何回覆這位人物的訊息時，聊天機器人會依照後台此人物的提升詞或是RAG 生成針對此訊息的回應或是地雷區分析
3. 多角色建立：從系統內新增人物項目（如A女、B男、老闆）
